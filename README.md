# 10_Gitリソース

このフォルダが、GitHubリポジトリ（[doujin-kaikei](https://github.com/grace-ver2/doujin-kaikei)）の実体（`.git`）を持つ場所。**このフォルダの配下だけがGit管理対象**で、`94_同人活動経費管理ツール`の他のフォルダ（`01_全体構成`・`02_データモデリング`・`03_リソース構築`・`99_参考ドキュメント`等）は対象外。

## なぜこの構成なのか

このリポジトリは将来的に**公開**し、他のユーザーが同じ環境を再現できるようにする予定。実プロジェクト側のフォルダには検討過程や実データへの参照が含まれうるため、Git管理の範囲をこのフォルダに限定することで、実データが公開リポジトリに紛れ込むリスクを構造的に防いでいる。詳しくは[データ取扱いルール.md](データ取扱いルール.md)を参照。

## 現在の状態

まだ公開用コンテンツの整備前の段階（フォルダ・Gitリポジトリの器を用意しただけ）。今後、実プロジェクト側の`01_全体構成`・`02_データモデリング`・`03_リソース構築`を元に、個人環境固有の値や実データへの言及を取り除いた公開用ドキュメントをこの配下に追加していく。

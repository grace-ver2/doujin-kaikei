## マスタ系
```mermaid
erDiagram
    頒布物種別マスタ ||--o{ 頒布物マスタ : "多:1"

    頒布物種別マスタ {
        string 頒布種別ID PK
        string 頒布物種別名
    }
    頒布物マスタ {
        uuid 頒布物ID PK
        string タイトル
        string 頒布物種別ID FK
        date 初版発行日
        string 頒布物イメージパス
    }
    イベントマスタ {
        string イベントID PK
        string イベント名
        date 開催開始日
        date 開催終了日
    }
    頒布種別マスタ {
        uuid 頒布種別ID PK
        string 頒布種別名
        bool 経費計上要否
        bool みなし売上要否
        bool 取消区分
    }
    経費科目マスタ {
        uuid 経費科目ID PK
        string 科目名
        string 対応する決算書科目
        bool ユーザー追加フラグ
    }
```

## 発注・在庫系
```mermaid
erDiagram
    発注 ||--o{ 発注明細 : "1:多"
    頒布物マスタ ||--o{ 発注明細 : "多:1"
    発注明細 ||--o{ 在庫管理 : "1:多"
    頒布物マスタ ||--o{ 在庫管理 : "多:1"
    頒布物マスタ ||--o{ 在庫移動 : "多:1"
    在庫拠点マスタ ||--o{ 在庫移動 : "移動元／移動先として2回参照"
    頒布 ||--o{ 在庫移動 : "1:多（任意）"
    頒布明細 ||--o{ 在庫移動 : "1:多（任意、関連トランザクションIDとセット）"
    在庫移動 ||--o{ 在庫移動明細 : "1:多"
    在庫管理 ||--o{ 在庫移動明細 : "多:1"

    発注 {
        uuid 発注ID PK
        string 注文番号
        int 発注金額
        int 送料
        int 割引適用額
        date 発注日
    }
    発注明細 {
        uuid 発注ID PK, FK
        uuid 発注明細ID PK
        uuid 発注商品 FK
        int 部数
        int 余部
        int 小計
        int 版数
    }
    在庫管理 {
        uuid 在庫ID PK
        uuid 頒布物ID FK
        int 初期数量
        uuid 発注ID FK
        uuid 発注明細ID FK
        date 入庫日
        int 単位あたり原価
    }
    在庫拠点マスタ {
        uuid 拠点ID PK
        string 拠点名
        string 拠点区分
        int 委託手数料
    }
    在庫移動 {
        uuid 移動ID PK
        uuid 頒布物ID FK
        uuid 移動元拠点ID FK
        uuid 移動先拠点ID FK
        int 数量
        date 移動日
        uuid 関連トランザクションID FK
        uuid 関連頒布明細ID FK
    }
    在庫移動明細 {
        uuid 移動ID PK, FK
        uuid 在庫ID PK, FK
        int 数量
    }
```
先入先出法の評価は、在庫移動明細をロット（在庫ID）・拠点ごとに集計するだけで求まる（詳細は`検証_2026-09-08_トランザクションフロー.md`を参照）。

## レジ連携系
```mermaid
erDiagram
    イベントマスタ ||--o{ イベント頒布物マスタ : "1:多（任意）"
    頒布物マスタ ||--o{ イベント頒布物マスタ : "多:1（任意）"
    セットマスタ ||--o{ イベント頒布物マスタ : "多:1（任意）"

    イベント頒布物マスタ {
        string イベント頒布物ID PK
        string イベントID FK
        uuid 頒布物ID FK
        uuid セットID FK
        string 頒布物名
        string 頒布物種別ID FK
        string 頒布物種別
        int 頒布価格
        int 持ち込み数
        string 頒布物イメージパス
    }
```
イベントアプリ（レジ）のオフライン利用・表示速度のため、頒布物名・頒布物種別・イメージパスをあえて非正規化して保持する（第3回）。`頒布物ID`と`セットID`は頒布明細と同じく排他的な任意項目。
